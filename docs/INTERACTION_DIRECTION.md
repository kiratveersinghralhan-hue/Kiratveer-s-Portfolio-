## Original concept: KR / Digital Practice

A dark studio volume opens into working products. Ink, graphite, bone typography and muted metallic details define the practice; individual projects own a controlled secondary palette. Modern sans typography leads. Serif is reserved for personal/fashion accents.

1. **Entry:** 1.6-second typographic shutter: Design / Code / AI / Motion resolve into KR. Skip is available; reduced motion and repeat navigation bypass it.
2. **Hero into book:** one continuous pinned root. A physical cloth book with a metallic KR relief is already visible in the first viewport. Pointer movement adjusts the camera subtly. The cover opens, page spreads turn, and a project plane moves toward the visitor.
3. **Project worlds:** QORTRA separates explicitly labeled conceptual layers for context, assistance, approval and action. Real travel screens follow a route through depth; industrial screens move with structured alignment; fashion uses slower masking and automotive work connects to real film.
4. **Film room:** one active full-viewport film composition with a selectable film strip, explicit sound control and native accessible playback. Portrait originals retain their proportions against a cinematic stage.
5. **Practice:** an interactive discipline index; a horizontal process track; engagement modes reveal scope and alter the surrounding composition while retaining the existing currency calculation.
6. **Person and invitation:** real photographs anchor the human identity. Start Project opens `/start-project/`, an eight-step brief, and confirmed Formspree success opens `/thank-you/`.
